## 경유 데이터 담당 선택본 (2026-10-01)

최종 학습 데이터로 **2008-04-15~2026-09-30의 6,743행 확장본**을 선택했습니다.
파일은 `data/processed/diesel_features_2008_spliced.csv`이며 컬럼 순서는
`date,diesel_price,singapore_diesel_price,usd_krw,tax_or_supply_feature`입니다.
`diesel_price`는 원/L, `singapore_diesel_price`는 USD/bbl,
`usd_krw`는 KRW/USD, `tax_or_supply_feature`는 경유 탄력세율 인하율(%)입니다.
2008-04-15~2012-12-03의 **1,694행 국제가격은 0.001% 직접 실측이 아니라
0.05% 실측에 평균 스프레드를 더한 추정값**입니다. 출처는 별도
`diesel_features_2008_provenance.csv`에 날짜별로 표시합니다.
2012-12-04~2026-09-30의 5,049행 실측 기준본은 비교용으로 보존합니다.

서빙 출력은 기준일 다음날부터 7일씩 묶은 **1·2·3·4주차 평균 경유 가격 4개**입니다.
데이터 담당의 `build_diesel_weekly_sequences(rows, seq_len)`은 이 정답을 생성하며,
과거 입력 길이 `seq_len`은 모델 담당이 확정할 때 전달합니다.
현재 `main`의 업로드·모델·서빙 계약은 아직 이전 휘발유 컬럼을 사용하므로,
이 데이터 파일을 기존 API에 바로 업로드하지 않습니다. 아래 휘발유 설명은
기존 `main` 경로의 기록입니다.

`data/sample_gasoline_prices.csv`는 **120일 합성 예제**입니다. 실측 데이터나 성능 증빙으로 쓰지 않습니다.
실측 원본은 아래 절차로 받아 `data/raw/`에 두며, 원본 파일은 커밋하지 않습니다(`data/raw/.gitignore`).

## 1. 휘발유 가격 (`gasoline_price`)

| 항목 | 내용 |
|---|---|
| 출처 | 한국석유공사 오피넷 <https://www.opinet.co.kr> |
| 메뉴 | 국내유가통계 → 주유소 → 평균판매가격 → **제품별** 탭 |
| 조회 조건 | 구분 **일간**, 기간 지정, 제품 **보통휘발유** |
| 저장 | **CSV저장** 버튼 → `data/raw/opinet_gasoline.csv`로 저장 |
| 의미 | 전국 주유소 보통휘발유 평균 판매가격 (부가세 포함) |
| 단위 / 주기 | 원/L, 일간 (주말·공휴일 포함 매일) |
| 원본 형식 | CP949, 헤더 `구분,고급휘발유,보통휘발유,자동차용경유,실내등유`, 날짜 `2026년09월26일` |
| 이용 조건 | 공개 조회 데이터. 재배포 조건은 오피넷 이용약관 확인 전까지 원본을 커밋하지 않음 |

변환 확인:

```bash
.venv/bin/python -m data.opinet data/raw/opinet_gasoline.csv
# 원본 N행 -> 변환 N행 / 기간 ... / 가격 범위 ...
```

### 변환 규칙 (`data/opinet.py`)

- 인코딩: CP949 원본과 UTF-8로 다시 저장한 파일을 모두 읽습니다.
- 날짜: `YYYY년MM월DD일`, `YY년MM월DD일`, ISO 등 → `YYYY-MM-DD`. 날짜순으로 정렬합니다.
- 중복: 같은 날짜·같은 값이면 하나만 남기고, 값이 다르면 오류입니다(어느 값이 맞는지 판단 불가).
- 누락: 평균판매가격은 매일 집계되므로 날짜가 빠지면 **오류**입니다. 앞뒤 값으로 보간하지 않습니다.
  (미래 값을 끌어오는 보간은 예측 시점에 알 수 없는 정보이므로 금지합니다.)
- 비정상 값: 0 이하, 빈 값, NaN/Infinity는 오류입니다.
- 원본 보존: 원본은 `data/raw/`에 그대로 두고, 변환은 항상 원본에서 다시 수행합니다(같은 원본 → 같은 결과).

## 4. 유류세 인하율 (`tax_or_supply_feature`)

- 의미: 해당일에 시행 중인 **휘발유 유류세 인하율(%)**. 0이면 인하 없음.
- 원본: `data/reference/gasoline_fuel_tax_cut.csv` (시행 구간표, 출처 기록). 구간은 빈틈·겹침이 없어야 합니다.
- 구간표 밖의 날짜는 추정하지 않고 오류 처리합니다. 2024년 이후 데이터를 쓰려면 기획재정부 고시를 확인해 구간을 추가하세요.
- 2023년 행(25%)은 연중 연장 고시를 추가로 확인해야 합니다.
- **공급 차질**은 일별 관측 지표가 없어서 피처로 넣지 않고, AIOps 드리프트 시나리오로만 다룹니다.

## 5. 시점 정합 (데이터 누수 방지)

D일 행에는 **D일 예측 시점에 이미 공개된 값**만 들어갑니다 (`data/external.py`).

| 피처 | D일 행에 들어가는 값 | 이유 |
|---|---|---|
| `crude_oil_price` | D-1일 이전 가장 최근 거래일 값 | 두바이 현물은 싱가포르 장 마감 기준이라 D일 값은 늦게 공개될 수 있음 |
| `usd_krw` | D일 이전(당일 포함) 가장 최근 영업일 값 | 매매기준율은 D일 오전에 고시됨 |
| `tax_or_supply_feature` | D일 시행 중인 인하율 | 시행일이 사전 고시되는 정책값 |

- 주말·휴일은 **이전** 관측값을 그대로 씁니다. 뒤 날짜 값으로 채우는 보간은 하지 않습니다.
- 마지막 관측값이 7일보다 오래됐으면 원본 누락으로 보고 오류 처리합니다.
- 맨 앞 날짜 중 공개된 외부 값이 없는 행은 추정하지 않고 제외합니다. 그래서 국제유가·환율은 휘발유 시작일보다 2주 정도 앞에서부터 받아 두세요.

### 국내 경유 원본 검증 증빙 (#25, 2026-10-01)

오피넷에서 받은 두 원본을 날짜 순으로 합쳐 `date,diesel_price`(원/L)로 변환했습니다.
이 표의 해시는 검증에 사용한 **로컬 원본의 식별값**이며, 원본 파일 자체는 Git에 올리지 않습니다.

| 원본 파일 | SHA-256 | 데이터 행 수 |
|---|---|---:|
| `opinet_diesel_2012_2023.csv` | `7f84c2c230cc8ae2386656154a40e3e4793526bd965fc42408f8d4316b63d99f` | 3,955 |
| `opinet_diesel.csv` | `8c25468c7248839f079db914689246e0401435523dba26912fd279b3d3fa7b35` | 1,097 |

변환 결과는 **5,052행(2012-12-01~2026-09-30)**, 가격 범위는
**1,058.75~2,167.66원/L**입니다. 날짜 고유값도 5,052개이며, 시작일과 종료일 사이의
달력 일수도 5,052일입니다. 따라서 두 파일을 이은 구간에 중복 날짜나 빠진 날짜가 없습니다.
모든 가격은 양수입니다. 이 수치는 국내 경유 **원본 변환**의 검증 결과입니다.
국제가격을 붙여 만든 최종 후보 CSV는 최초 사용 가능일 전 3일을 제외한 5,049행이므로
두 행 수를 혼동하지 않습니다.

재현 명령(저장소 루트에서 실행):

```bash
.venv/bin/python -c 'from data.opinet import load_opinet_diesel_many; r=load_opinet_diesel_many(["data/raw/opinet_diesel_2012_2023.csv","data/raw/opinet_diesel.csv"]); p=[x["diesel_price"] for x in r]; print(len(r),r[0]["date"],r[-1]["date"],min(p),max(p))'
# 5052 2012-12-01 2026-09-30 1058.75 2167.66
```

경유 원본만 확인하려면:

```bash
.venv/bin/python -c 'from data.opinet import load_opinet_diesel; import sys; rows=load_opinet_diesel(sys.argv[1]); print(len(rows), rows[0], rows[-1])' data/raw/opinet_diesel.csv
```

기간별 원본을 아래 이름으로 `data/raw/`에 보관합니다. 파일은 커밋하지 않습니다.

| 파일 | 기간 / 내용 |
|---|---|
| `opinet_diesel_2012_2023.csv` | 2012-12-01 ~ 2023-09-29, 국내 자동차용경유 |
| `opinet_diesel.csv` | 2023-09-30 ~ 2026-09-30, 국내 자동차용경유 |
| `opinet_singapore_diesel_2012_2023.csv` | 2012-12-01 ~ 2023-09-28, 싱가포르 경유(0.001%) |
| `opinet_singapore_diesel_2023_2026.csv` | 2023-09-29 ~ 2026-09-30, 싱가포르 경유(0.001%) |
| `ecos_usdkrw_2012_2026.csv` | 2012-11-15 ~ 2026-09-30 범위의 ECOS 환율. 앞쪽 여유분 포함 |

ECOS 환율은 `data.ecos --start 20121115 --end 20260930 --out data/raw/ecos_usdkrw_2012_2026.csv`로
받습니다. API 키는 `ECOS_API_KEY` 환경변수에만 넣고 파일이나 명령 이력에 남기지 않습니다.
싱가포르 가격은 D-1일 이전, 환율은 D일 이전(당일 포함)의 최근 관측값을 사용합니다.
휴장일에는 **이전 값**을 쓰고 미래 값으로 보간하지 않습니다. 싱가포르 가격은 7일,
환율은 10일보다 오래된 값을 거부합니다. 환율 한도는 ECOS 실측의 최장 휴장 간격
(2017-09-29 다음 관측 2017-10-10)을 반영한 값입니다. 경유 유류세는 D일 시행값입니다.

```bash
.venv/bin/python -m data.build_diesel_dataset
# 입력: 위 표의 국내 경유 2개, 싱가포르 경유 2개, ECOS 환율 1개
# 출력: data/processed/diesel_features.csv (실측 원본/가공본은 커밋하지 않음)
```

2026-10-01 실측 생성 결과: 국내 경유 5,052일 중 국제가격 최초 사용 가능일 전 3일을 제외해
**5,049행(2012-12-04~2026-09-30)**을 만들었습니다. 싱가포르 경유 원본은 날짜 5,052행 중
거래일 가격 3,463행, 휴장일 빈 값 1,589행입니다. ECOS 환율 관측은 3,418행입니다.
결과의 날짜 누락·빈 피처·비유한값은 0건이며, 20일 입력과 다음날 정답으로 만들 수 있는
연속 구간은 5,029개입니다. 이는 실제 원본을 결합한 데이터이며 합성 샘플이 아닙니다.

모델 담당이 같은 기간의 입력원을 비교할 때는 2023-09-30~2026-09-30의 기존 두바이유
`opinet_crude.csv`와 이번 싱가포르 경유 원본을 구분해야 합니다. 이 기간의 유효 국제가격
관측은 각각 755행이며, 둘 다 USD/bbl이지만 **서로 다른 상품 가격**입니다. 이번 결과
컬럼은 `singapore_diesel_price`이고 기존 두바이유 컬럼 `crude_oil_price`로 이름만 바꿔
해석하지 않습니다. 성능 개선 여부는 같은 학습·검증 분할에서 모델 담당자가 평가해야 합니다.

경유 유류세 원본은 [교통·에너지·환경세법 시행령 제정·개정이유](https://law.go.kr/LSW/lsRvsRsnListP.do?chrClsCd=010202&lsId=002619&lsRvsGubun=all)입니다.
`data/reference/diesel_fuel_tax_cut.csv`에 시행 구간별 **경유** 탄력세율(원/L)과 법령 번호를 기록하고
`(1 - 탄력세율 / 375) × 100`을 소수 첫째 자리로 반올림한 값을 피처로 사용합니다. 휘발유 표와 혼용하지 않습니다.
구간표 밖의 날짜는 추정하지 않고 오류로 처리합니다.

싱가포르 경유는 국내 주유소 가격에 영향을 주는 국제 석유제품 가격입니다. 국내 판매가격과 동일한
값이거나 이를 단독으로 결정하는 값은 아닙니다. [오피넷 국제 석유제품 안내](https://www.opinet.co.kr/glopopdSelect.do)는
경유(0.001%)가 2012-12-01부터 조사되고 현지 시차로 T일 가격을 T+1일에 조사한다고 설명합니다.
경유 세율의 과거 구간은 [국가법령정보센터 개정문](https://www.law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=002619&lsRvsGubun=all)에서 확인했습니다.

`singapore_diesel_price`는 #31에서 **데이터 담당이 팀에 전달하는 컬럼명**으로 정했습니다.
두바이유의 `crude_oil_price`와 다른 상품이므로 이름을 재사용하지 않습니다. 기존 공통 계약은
여전히 `crude_oil_price`와 `gasoline_price`를 사용합니다. PM·모델·서빙·AIOps 담당이 이
입력명을 공통 계약과 코드에 반영하기 전에는 이 CSV를 기존 서비스에 업로드하지 않습니다.

### 2008~2012년 접합 제안 검토 (#28)

오피넷의 경유(0.05%)는 2008-01-02부터 확인되지만 경유(0.001%)와 **다른 규격**입니다.
`data/raw/opinet_singapore_diesel_grade_overlap_2012_2013.csv`의 첫 60개 겹치는 거래일에서
`0.001% - 0.05%` 차이 평균은 1.48 USD/bbl, 표준편차는 약 0.36 USD/bbl입니다.
이 가격차는 당시 환율 1,083.5원/$와 [오피넷 단위환산표](https://www.opinet.co.kr/user/ofunit/getOfunitSelect.do)의
1배럴=158.984L로 환산하면 약 **10.1원/L**입니다. 1.4원/L가 아닙니다.
현재 5,049행 실측본에는 0.05%와 추정 스프레드를 섞지 않았습니다. 2008~2012년 접합은
별도 실험으로 두고, 동일한 검증 기간에서 실측 0.001%만 쓴 기준본과 비교해야 합니다.

### 2008년 선택본 (#33)

기존 `diesel_features.csv`(2012-12-04~2026-09-30, 5,049행)는 실측 기준본으로 그대로 둡니다.
2008-04-15~2026-09-30의 **6,743행 선택본**은 별도
`diesel_features_2008_spliced.csv`로 생성합니다. 국내 경유 가격과 원/달러 환율은
실측입니다. **2008-04-15~2012-12-03의 국제가격 1,694행은 직접 관측한 0.001% 가격이
아닙니다.** 오피넷 경유(0.05%) 실측에 겹침 첫 60거래일의
`0.001% - 0.05%` 평균 **1.479667 USD/bbl**를 더한 규격 접합 추정값입니다.
2012-12-04 이후 5,049행은 기존 실측 기준본과 행별로 완전히 같습니다.

|---|---|---|
| `opinet_diesel_2008_2012.csv` | 국내 자동차용경유 2008-04-15~2012-11-30, 1,691일 | `d0a9dca70826cf22612cdc0c1ad145319e3236477b52b68a42befe7a38186424` |

오피넷 국제 원본 1,707일에는 휴장일 빈 값 534일이 포함되어 있으며, 실제 0.05% 가격 관측은
1,173일입니다(47.63~182.46 USD/bbl). 국내 경유 1,691일은 빠진 날짜가 없고
1,268.45~1,947.75원/L입니다. ECOS 환율 1,173관측은 974.6~1,573.6원/USD입니다.
세 원본 모두 화면에서 받은 그대로 보관했습니다. 원본을 다시 받을 때는 오피넷의 국내
주유소 제품별 평균판매가격 **일간·자동차용경유**, 국제 석유제품 **일간·경유(0.05%)·`$`**,
ECOS의 **3.1.1.1 주요국 통화의 대원화환율 → 원/미국달러(매매기준율) → 일별 CSV**를
선택합니다. 겹침 60거래일 계산에는 2012-12-01~2013-02-28의 오피넷 0.001%와
0.05% 두 열을 함께 받은 원본을 사용합니다.

오피넷 국제가격은 화면에서 **`$`(USD/bbl)** 단위로 받았습니다. ECOS 웹 CSV는 날짜가
열이고 통화가 행인 원본 형식이며, 로더는 `원/미국달러(매매기준율)` 행만 선택합니다.
국제가격은 D-1일 이전, 환율은 D일 이전(당일 포함)의 가장 최근 거래일 값을 씁니다.
휴장일을 미래 관측값으로 보간하지 않습니다. `singapore_diesel_spliced`는 학습 입력에
섞지 않고 별도 `diesel_features_2008_provenance.csv`에 날짜별로 기록합니다.

2008~2009년 경유 탄력세율은 [제20744호](https://law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=002619&lsRvsGubun=all)의
2008-03-10 특례 335원/L, [제21065호](https://law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=002619&lsRvsGubun=all)의
2008-10-07 특례 328원/L·2009-01-01 본칙 364원/L,
[제21494호](https://law.go.kr/LSW/nwRvsLsInfoR.do?lsiSeq=93617)의 2009-05-21부터
375원/L을 적용했습니다. 피처의 인하율은 **375원/L 대비** 비율을 소수 첫째 자리로
반올림한 값으로, 당시 유류세 전체의 인하율을 뜻하지 않습니다.
