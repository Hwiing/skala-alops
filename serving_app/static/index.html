경유 주간 예측 데이터 업로드

data/uploads/는 여기서 업로드한 CSV만 쌓이는 곳입니다. 학습은 diesel_registry.py에 실제 경유 CSV 경로를 전달해 실행합니다. data/sample_diesel_prices.csv는 120행 합성 예제이므로 아래 업로드 최소 행 수에 못 미칩니다. (컬럼: date, diesel_price, singapore_diesel_price, usd_krw, tax_or_supply_feature · 최소 175행).

드리프트 시뮬레이션

일별 수익률(log return) 기반 랜덤워크로 정상/드리프트 배치를 만들어 /predict/batch-test로 전송합니다. 드리프트 배치를 보내면 아래 파이프라인이 감지 → 재학습 → (게이트 통과 시) 재배포까지 진행됩니다.
