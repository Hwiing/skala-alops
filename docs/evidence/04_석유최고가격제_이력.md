# 04. 석유 최고가격제 이력 (2026-03-13 ~ 현재)

수집일: 2026-09-30 · 방법: 산업통상부 보도자료·언론(에이전트) · 데이터: `skala-alops/data/raw/study/price_cap_history.csv`

- 1997년 유가 자유화 이후 약 30년 만의 가격 상한. 이란 전쟁으로 국제유가 100달러 돌파가 배경.
- 대상: **정유사 → 주유소 공급가(세후)**. 주유소 판매가(소매가)에는 적용 안 됨.
- 산정: 기준가격(전쟁 전 2월 마지막 주 세전 공급가) × 직전 기간 MOPS 변동률 + 제세금. 실제로는 3차부터 "민생 안정"을 이유로 산식과 무관하게 여러 차례 동결.
- 조정 주기: 2주 → 6차부터 4주.
