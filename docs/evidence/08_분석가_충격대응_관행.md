# 08. 예측 불가 충격·정책 개입·구조변화에 분석가·기관은 어떻게 대응하나

조사일: 2026-10-01 · 방법: 웹 검색(에이전트). 원문을 직접 확인한 문장은 "확인", 검색 요약에만 의존한 것은 "요약", 찾지 못한 것은 "미확인"으로 적었다.
배경: 2026-03 전쟁으로 원가가 급등한 직후 3/13 석유 최고가격제가 기습 도입됨(04 참고). 원가를 따라가던 모델이 크게 틀림.

## 핵심 결론
1. **기관 예측은 "모델 + 사람 판단"이다.** EIA STEO는 모델 식마다 보정항(add factor)을 두고 규제 변경 같은 "이미 알려진 일"을 분석가가 직접 넣는다. 유가 자체도 두 모델을 참고만 하고 최종값은 분석가 판단으로 정한다(확인). Fed 기준 전망도 판단 기반이다.
2. **충격기에는 점 하나 대신 시나리오와 구간을 낸다.** ECB는 2026-06에 기준 + 완만·불리·심각 3개 시나리오를 냈고, EIA는 "호르무즈가 언제 다시 열리나"라는 가정을 명시한다. EIA의 신뢰구간은 옵션 내재변동성에서 나오므로 시장이 불안하면 자동으로 넓어진다.
3. **결합과 random walk 쪽으로 당기기가 기본 방어다.** 여러 모델을 동일가중으로 결합하면 단일 모델보다 낫고 무변화(naive) 예측도 이긴다(Baumeister·Kilian). 정교한 가중보다 단순 평균이 더 나은 경우가 많다(결합 퍼즐).
4. **구조변화 뒤에는 최근 데이터에 맞추되 오래된 데이터도 버리지 않는다.** 이건 편향과 분산의 맞교환이다(Pesaran·Timmermann). 수준 대신 변화량으로 모델링하거나 절편을 보정하는 방법(Clements·Hendry)이 변화에 강하다. 트리 모델은 학습 범위 밖으로 외삽하지 못한다.
5. **국내 주간 전망은 정성적이다.** "국제가는 2~3주 시차로 반영된다"는 규칙을 바탕으로 방향(상승·보합·하락)만 말한다. 정책이 나오면 "언제부터 얼마나 반영되는지(1~2주)"를 덧붙인다. 정량 모델로 전망한다는 공개 자료는 확인하지 못했다(미확인).
