# 02. 국내 주유소 소매가 결정 구조와 설명변수 (국내 연구)

조사일: 2026-09-30 · 방법: 웹 검색(에이전트). "추정" 표시는 원문 수치 미확인.

## 핵심 결론
- 국내 소매가는 원유(두바이)보다 **싱가포르 국제제품가(MOPS) × 환율**을 따라가며 **2~3주** 늦게 움직인다. (2001년부터 제품가 연동)
- 소매가는 **정유사 공급가**에 1~2주 시차로 대칭 조정 (KEEI 2005, R² 평균 0.96).
- 2026년은 유류세 인하 재확대 + 석유 최고가격제(3/13~)로 **구조변화** → 별도 처리 필요.

## 가격 결정 구조
- 소매가 ≈ [정유사 세전 공급가 + 유류세 + 유통마진] × 1.1(부가세)
- 세전 공급가 ≈ MOPS($/bbl) × 환율 ÷ 159 + 관세·수입부과금(16원/L)·물류비 + 정유사 마진 (추정 분해)

### 유류세 (인하 전, 원/L)
| 항목 | 휘발유 | 경유 |
|---|---|---|
| 교통에너지환경세 (탄력세율; 법정 475/340) | 529 | 375 |
| 교육세 (교통세 15%) | 79.35 | 56.25 |
| 주행세 (교통세 26%) | 137.54 | 97.50 |
| **합계** | **745.89** | **528.75** |
| 부가세 포함 | 약 820 | 약 581 |

## 모형과 성능
| 연구 | 모형 | 데이터 | 결과 |
|---|---|---|---|
| 김남제·김형건 (2023) | 비대칭 ECM, GARCH, ARDL | 오피넷 일별 5,374일 (2008~2022) | 전체 평균 비대칭 없음, 변동성이 비대칭 키움 |
| 경제연구 (2009) | ECM | 주간 1997~2009 | 초기 비대칭 → 이후 감소 |
| 장연재·김대욱 (2016) | 비대칭 ECM | 3개 유종 | 모든 유종 비대칭 |
| 오선아·허은녕 (2012) | 단계별 ECM | 원유→제품→도매→소매 | 도매 단계는 대칭+시차 |
| KEEI 이달석 (2005) | 회귀·ECM | 16개 시도 | 소매가는 도매가에 대칭 조정 (R² 0.96) |
| ML·LSTM | — | — | 오피넷 기반 소매가 LSTM 성능 보고 KCI 논문은 찾지 못함 |

실무 권장(추정): 비대칭 ECM을 baseline, MOPS×환율 t-1~t-3주, 공급가 t-1주, 정책 더미. 세금은 모델 밖에서 규칙으로 복원.
