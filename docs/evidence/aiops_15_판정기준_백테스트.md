# AIOps #15 드리프트 판정 기준 실측 백테스트

> 실측 경유 데이터(`diesel_features_2008_spliced.csv`, 2008-04-15 ~ 2026-09-30, 6,743행)와
> 서빙 모델과 같은 학습 코드(`diesel_training.fit`, LSTM seed 42·7·2026 평균 + 정책 규칙)로 검증했습니다.

## 방법

과거 1년을 "실시간 운영"처럼 다시 돌렸습니다 (`scripts/backtest_drift.py`).

1. 시험 구간(마지막 365일)을 떼고, **그 이전 데이터로만** 모델을 학습합니다 (미래 정보 누수 없음).
2. 시험 구간의 기준일마다 batch_test와 같은 짝 `{date, predicted[4], actual[4], naive}`를 만듭니다.
3. 기준일 28개씩 밀며 `drift_detector.evaluate()`로 판정합니다. 판정일 = 마지막 기준일 + 7일 (1주차 정답 도착일).

시험 구간은 성격이 다른 세 해입니다: 정상기(2019), 2022 우크라이나 전쟁 급등, 2026 전쟁·최고가격제.

```bash
python scripts/backtest_drift.py --test-end 2019-09-30 --out logs/backtest_2019.md --json logs/backtest_2019.json
python scripts/backtest_drift.py --test-end 2022-09-30 --out logs/backtest_2022.md --json logs/backtest_2022.json
python scripts/backtest_drift.py --test-end 2026-09-30 --out logs/backtest_2026.md --json logs/backtest_2026.json
```

## 결론: 하한 10원/L 추가

| 기준 | 정상기 2019 | 2022 우크라이나 | 2026 전쟁·최고가격제 |
|---|---|---|---|
| 기존: 1주차 RMSE > naive RMSE | 78일 (23%) | 16일 (5%) | 89일 (26%) |
| **변경: 위 조건 AND 1주차 RMSE > 10원** | **0일** | **0일** | **35일 (10%)** - 2026-04, 2026-07 |

- **기존 기준의 오탐**: 가격이 거의 고정된 시기에는 naive 오차가 1원 미만입니다. 그래서 모델 오차가 1~2원만 나와도
  "naive보다 나쁨"이 됩니다 (2019-08 모델 1.6 vs naive 0.7, 2025-10 1.5 vs 1.2, 2026-06 최고가격제 2.0 vs 0.7).
  정상기에도 23%의 날에 재학습이 걸리는데, 업무상 의미가 없는 오차입니다.
- **하한 10원 근거**: 정상기 1주차 naive RMSE는 약 10~13원입니다 (`docs/evidence/06` 정상기 naive 9.4~13.1원, 이번 백테스트 2018-11 14.9원).
  모델 오차가 이 수준보다 작으면, naive와의 상대 비교로는 문제가 아니라고 봅니다. 하한을 5·10·15·20원으로 바꿔 비교한 결과:

| 하한 | 2019 | 2022 | 2026 |
|---|---|---|---|
| 0 (기존) | 78 | 16 | 89 |
| 5원 | 0 | 12 | 40 |
| **10원** | **0** | **0** | **35** |
| 15원 | 0 | 0 | 35 |
| 20원 | 0 | 0 | 34 |

  10~20원 사이에서 결과가 거의 같아 기준이 안정적입니다. 그래서 가장 보수적인(빨리 잡는) 10원으로 정했습니다.
- **남는 drift는 실제 문제 구간입니다**: 2026-04(1주 오차 45.9원 vs naive 45.3원, 3/13 최고가격제 도입 뒤 모델이 상승 추세를 연장)와
  2026-07(26.0 vs 25.0). 둘 다 업무 허용 한도(50원)에 가까운 오차가 naive보다 큽니다.
- **급등 자체는 drift가 아닙니다**: 2022-03(모델 38.0 vs naive 48.2), 2026-03(67.5 vs 71.1)은 오차가 크지만 naive보다 작습니다.
  모두가 틀리는 충격기에 재학습해도 얻을 것이 없으므로 기준대로 동작한 것입니다.
- **한계**: 판정은 기준일 28개 + 정답 대기 7일이 필요해 충격 뒤 1~5주 늦게 울립니다. naive 비교 방식이라 급등기에는 낡은 모델의 오차가 가려질 수 있습니다.
