# 01. 국제 원유·석유제품 가격 예측 요인 (해외 애널리스트·학계)

조사일: 2026-09-30 · 방법: 웹 검색(에이전트). 데이터 출처 URL 일부는 기억 기반이라 사용 전 유효성 확인 필요. 투자은행 공개자료는 확인 못함.

## 핵심 결론
- **일간 유가 예측은 랜덤워크(어제값)를 이기기 매우 어렵다.** 이긴 사례는 대부분 월간·1개월 이상 시평이며, 예측 결합·제품 스프레드·고빈도 금융변수를 쓴 경우.
- 일간 "고정확도" ML 논문은 가격 수준 예측, 미래 정보 누수, 랜덤워크 미비교 사례가 많음(추정). 검증은 변화량 기준 + 랜덤워크 대비 Diebold-Mariano 검정 권장.

## 랜덤워크 대비 증거
| 구분 | 연구 | 결과 |
|---|---|---|
| 못 이김 | Alquist·Kilian·Vigfusson (Fed IFDP 2011) | 선물가·스프레드 예측이 1~12개월에서 대체로 무변화 예측보다 부정확 |
| 이김(월간) | Baumeister·Kilian 실시간 (CEPR DP8414) | 1개월 MSPE 최대 25%, 3개월 24% 감소 |
| 이김(결합) | Baumeister·Kilian (DP9569, DP10075) | 2년까지 모든 시평 우수, MSPE 3~29% 감소 |
| 이김(제품 스프레드) | Baumeister·Kilian·Zhou (BoC WP 2013-25) | MSPE 최대 20% 감소, 방향 적중 63% |
| 이김(고빈도 금융) | Degiannakis·Filis (Energy Economics 2018) | MIDAS로 월간 RMSE 약 68% 감소 |
| 이김(변수선택) | Miao 외 (Energy Economics 2017) | LASSO, MSPE 비율 0.873 |
