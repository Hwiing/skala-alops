# 03. 유류세 한시 인하율 이력 (재정경제부 원문 검증)

검증일: 2026-10-01 · 방법: 기획재정부(현 재정경제부) 보도자료 원문 대조(에이전트) · 데이터: `skala-alops/data/raw/study/fuel_tax_cut_verified.csv`

|---|---|---|---|---|

- LPG부탄: 2025-05~10 15%, 2025-11~2026-03 10%, 2026-03-27 확대 시 10% 유지 → 2026-05-01부터 25%.
- 원문 세액은 부가세 포함 금액만 제시(휘발유 820, 경유 581). 표의 원/L는 계산값이며 원문 대비 최대 3원 차이(시행령 반올림 추정).
- 미확인: law.go.kr 시행령 조문(동적 페이지로 수집 실패). 2022-04-05 물가관계장관회의는 정책브리핑과 2022-12-19 보도자료 표로 대체 확인.
- 2026-11-30 종료는 예정일.
